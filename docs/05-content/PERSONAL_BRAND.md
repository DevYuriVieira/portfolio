# Personal Brand

## Who I Am

My name is **Yuri Vieira Teixeira**.

I'm a Junior Software Engineer with a background in Production Engineering.

Technology has always been part of my life. Since I was young, I was fascinated by computers, video games, smartphones and how hardware and software work together. I wasn't only interested in using technology—I wanted to understand how it was built.

That curiosity eventually led me to Production Engineering, where I learned to analyze systems, identify bottlenecks, optimize processes and think from beginning to end instead of focusing only on isolated tasks.

Later, Software Engineering became the place where I found what I truly enjoy: designing and building software that solves real problems.

Today, those two worlds complement each other.

---

# My Perspective

I don't see software as just code.

I see it as a complete engineering process.

Every project starts long before writing the first line of code and continues long after the first release.

Understanding the problem.

Planning.

Architecture.

Communication.

Implementation.

Testing.

Maintenance.

Continuous improvement.

I enjoy participating in every stage of that journey.

---

# What Defines Me

I like building software with intention.

I enjoy thinking about architecture before implementation.

I like understanding why a solution exists before deciding how to build it.

I'm naturally curious and constantly studying new technologies, but I believe that good engineering is much more about solving problems than collecting frameworks.

---

# How I Like to Work

When I'm part of a project, I try to:

- understand the business before proposing solutions;
- communicate clearly with the team;
- respect deadlines and commitments;
- write clean, readable and maintainable code;
- deliver more value than originally requested whenever possible;
- continuously improve both the product and the development process.

I believe communication is one of the most important technical skills an engineer can have.

Many problems are solved faster through good conversations than through more code.

---

# Engineering Influence

Production Engineering still influences the way I build software every day.

Concepts such as:

- PDCA
- Lean Thinking
- Continuous Improvement
- Root Cause Analysis
- Process Optimization
- Systems Thinking
- 5W2H

naturally became part of how I approach software development.

For me, software is another type of production system—one where the raw material is information and the final product is a reliable experience for users.

# Technical Philosophy

- simple;
- scalable;
- maintainable;
- performant;
- accessible;
- easy for other developers to understand.
