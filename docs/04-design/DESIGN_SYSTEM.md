# Purpose

The Design System defines the visual language of the portfolio.

Every UI element must be built using these foundations.

Consistency is more important than creativity.

---

# Design Principles

- Minimal
- Premium
- Technical
- Elegant
- Purposeful
- Accessible

Animations should enhance the experience, never distract from it.

---

Heading

---

## Motion

Animations must feel:

- Smooth
- Intentional
- Responsive

Avoid:

- Bouncy effects
- Long delays
- Decorative motion

---

## Elevation

Keep shadows subtle.

Depth should be communicated primarily through spacing and contrast.

---

## Breakpoints

Mobile

Tablet

Desktop

Wide Desktop

Avoid component-specific breakpoints whenever possible.

---

## Containers

Use consistent content widths.

Do not create custom widths per section.

---

---

# Icons

Use a single icon family throughout the project.

Icons must have a consistent visual weight.

---

# Images

Prefer optimized formats.

Avoid decorative images without purpose.

Every image should contribute to the narrative.

---

# Accessibility

Minimum contrast must satisfy WCAG AA.

Interactive elements must have visible focus states.

Animations should respect reduced-motion preferences.

---

# Performance

Avoid heavy visual effects.

Prefer CSS transforms over layout-triggering animations.

GPU-friendly animations should be prioritized.
